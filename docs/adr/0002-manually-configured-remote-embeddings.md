# 使用手动配置的远程 embedding 服务

首个语义版本由用户手动配置远程 embedding 模型，避免将本地模型分发和推理运行时纳入初期交付。LanceDB 数据库仍嵌入桌面本地，远程服务仅负责将授权范围的文本转成向量；关键词搜索独立于该服务。

首个接口限定为 OpenAI-compatible Bearer JSON embeddings 子集，用户填写 API base URL、模型 ID 和密钥引用。密钥使用 Obsidian SecretStorage；维度由测试响应确认，可选 dimensions 默认不发送，不预设厂商或模型。

语义范围由用户明确选择目录或全部 Markdown，支持排除项；发送正文片段及正文内标题上下文，不额外附加文件名、路径、标签或 frontmatter。首次手动建立语义索引后自动增量；普通关键词输入不调用模型，选择语义搜索模式或执行相关笔记命令时才发送查询。

保存配置不发请求，手动连接测试仅发送内置公开测试句。远程服务不可用时继续提供关键词搜索。模型配置变化需要区分向量空间，即便新旧模型向量维度相同，也不得混用；全量重建由用户明确发起。
