# M3 远程语义与混合搜索验证

日期：2026-10-07。M3 已按个人自用范围实现。关键词搜索继续离线运行，语义功能需手动配置和启用。外部请求验证使用合成文本和受控响应；真实 Obsidian 使用本机 HTTP 服务验证完整请求链路，未调用商用模型或发送用户已有笔记。

## 已实现的行为

- 设置包含 API base URL、模型、SecretStorage 密钥引用、可选 dimensions、片段长度、批大小、并发上限和等待时限。普通设置只保存密钥名称。
- 保存配置不发请求，并暂停远程工作。连接测试仅发送两条内置公开中英句子，校验返回的数量、index、有限非零向量和统一维度。
- 首次建库需要测试连接、选择范围并确认发送。仅发送正文片段和正文标题上下文；不追加文件名、路径、frontmatter 或标签元数据。正文中的私人信息仍属于发送内容。
- 已启用范围内按笔记版本增量更新，片段按输入哈希复用。元数据修改、改名和位置变化可以更新本地记录而不重复生成相同文本的向量。
- 范围缩小立即停止待发送工作；恢复使用缩小后的授权范围。范围扩大、模型或预处理变化需要手动建库。取消、编辑和删除后的迟到结果不可重新成为有效结果。
- 向量空间由 endpoint、模型、实际维度及预处理配置区分，密钥轮换不改变空间。语义数据库使用独立格式号和代次；完成后原子切换，未完成的重建不取代已有索引。
- 本地使用 LanceDB 的 cosine IVF_FLAT ANN，按笔记聚合候选片段，最多返回 50 篇笔记。已有向量在首次查询时本地补建 ANN；新代次建好 ANN 才发布。语义查询只在 Enter 或按钮提交后发送；输入、模式切换和索引刷新不发查询。路径与标签过滤在本地执行。ANN 实现及实测详见 [ANN 验证报告](ANN-VALIDATION.md)。
- 混合搜索对最多 50 个关键词候选和 50 个语义候选做 reciprocal rank fusion；不相加 BM25 与 cosine 原始分数。界面的混合结果数量描述候选集合。
- 网络/限流最多重试两次；认证、契约、维度错误或重试耗尽暂停远程工作。超时和取消不承诺停止底层 HTTP，请求直到真正结束前仍占用并发名额，迟到响应被丢弃。
- 缓存缺失或不兼容要求手动重建，不自动重新发送整个范围。关键词重建会暂停远程工作。插件停用清理弹窗、队列和监听。

## 可重复原生与契约检查

```sh
npm run package:darwin-arm64
npm run verify:m0
npm run verify:m1
npm run verify:m2
npm run verify:m3
npm run verify:ann
npm run lint
git diff --check
```

`verify:m3` 解压独立 ZIP，使用外部 Node 24.20.0 与用户全局 SDK（本次观测为 0.39.0），不从开发目录加载 SDK。受控 transport 检查 HTTP 方法、路径、Bearer 头和 JSON 载荷；原生向量操作通过真实 IPC 子进程执行。

通过的检查包括：

- 乱序响应正确对齐；数量错误、重复/缺失 index、NaN、零向量和维度不符被拒绝。
- 默认关闭、保存设置和测试连接不会发送笔记；测试连接的 dimensions 默认不发送。
- 超时请求保留物理并发名额；取消后不再发送；限流最多三次尝试，错误信息不包含提供方响应正文。
- 选定目录、本地排除项、空正文、中文片段与 UTF-16 原文偏移。
- 仅变化段落发送；元数据修改和改名不发新 embedding；请求期间删除笔记后不会保留有效旧向量。
- 范围缩小后清理无效记录；扩大配置并选择恢复不会发送未经新建库授权的笔记。
- 同维度模型切换隔离；暂停重建保留旧代次；旧代次写入和错误空间查询被拒绝。
- HTTP 401 和维度错误暂停远程工作，关键词查询仍成功。
- 向量缓存重新打开后仍可查询；缓存缺失不会自动发起远程重建。

M0–M2 原有回归通过。构建通过，lint 零错误，保留既有的新版设置搜索声明 API 提示。没有新增运行时依赖或固定 SDK/Arrow 版本。

## 真实 Obsidian

环境为 macOS 15.7.3 arm64、Obsidian 1.13.7、Electron 43.3.0；使用独立 profile、临时 vault 和本机 `127.0.0.1` HTTP 服务，服务返回三维合成向量。临时库只有两篇选定笔记和一篇排除笔记。下表为 M3 初始实现时的宿主验证；ANN 改动后重新运行了打包产物 IPC 回归及原生 ANN 验证，未重复整套 GUI 操作。

| 场景 | 结果 |
| --- | --- |
| 启动、填写配置、保存 | 0 次 embedding 请求 |
| 设置界面与密钥 | SecretComponent 正常显示；`data.json` 不含测试密钥值 |
| 选择连接测试 | 1 次请求，包含两条内置句子；正确追加 `/embeddings`，Bearer 认证通过 |
| 确认建库 | 2 篇笔记，5 个正文片段，2 次请求；排除笔记和 frontmatter 别名未发送 |
| 选择语义模式并输入 | 请求数不增加 |
| 按 Enter 提交语义查询 | 返回 `Work/Planets.md`，打开后选中原文“星球 orbit around a star.”段落 |
| 提交混合查询“猫” | `Work/Cats.md` 排第一，候选按笔记去重 |
| 保存正文变化 | 仅新增 1 次请求，包含变化段落；关键词查询同时可用 |
| 服务返回 HTTP 401 | 远程状态暂停；关键词查询仍返回结果 |
| 停用插件 | 搜索弹窗被清理 |
| 重新安装 ZIP 并启用插件 | 2 篇向量记录恢复，未增加 HTTP 请求，普通设置仍不含密钥 |
